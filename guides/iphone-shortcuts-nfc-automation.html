NFC tag automations with iPhone Shortcuts

Updated 15 October 2026

An NFC tag on your bedside table, desk or car dashboard can run any shortcut when you tap your iPhone on it. There are two ways to set it up: the NFC trigger built into the Shortcuts app, and a tag that stores a link that runs a named shortcut. They behave differently, so here's how each works and when to use it.

Method 1: a Personal Automation with the NFC trigger

This is the hands-free option: tap the tag and the shortcut runs, no app to open first. The NFC trigger is available on iPhone XS, iPhone XR and later.

  1. Open Automation. Open the Shortcuts app and go to the Automation tab.
  2. Create an automation. Tap + (or New Automation) and choose NFC.
  3. Scan the tag. Tap Scan and hold the top of your iPhone near the tag, then give the tag a name such as Bedside.
  4. Choose how it runs. Select Run Immediately so it runs without asking, or Run After Confirmation. On older iOS versions, turn off Ask Before Running.
  5. Pick the actions. Tap Next and choose an existing shortcut or build new actions, then tap Done.
  6. Tap to test. With your iPhone awake, tap the tag. A notification confirms the automation ran.

What to know

  • The tag's content doesn't matter. Shortcuts identifies the tag by its unique ID, so a blank tag, a written tag or even a locked tag works. A blank tag is best: a tag that also holds a web link may show that link's notification as well.
  • It only runs on your iPhone. Automations live on your device. Someone else tapping the same tag won't run your automation.
  • Rewriting the tag is fine. The ID doesn't change when you write or erase a tag. Replacing the tag with a new one means scanning it again in the automation.
  • The iPhone has to be in use. iOS reads tags in the background only while the iPhone is in use, and not while the camera or Wallet is open, in Airplane Mode, or before the first unlock after a restart.

Method 2: a tag that runs a named shortcut

The Shortcuts app has a link format that runs a shortcut by name: shortcuts://run-shortcut?name=Lights%20Off. NFC Toolkit's Run a Shortcut template writes that link for you and takes care of spaces and special characters.

  1. In NFC Toolkit, open the Write tab and tap Run a Shortcut.
  2. Type the shortcut's name exactly, including capitals.
  3. Tap Done, then Write to tag and hold your iPhone to the tag.

To use it, scan the tag with NFC Toolkit (the Scan tab, the Home Screen widget, or the Scan NFC Tag action) and tap Open. The Shortcuts app opens and runs the shortcut.

Important limit: the iPhone's built-in background tag reader only opens web links and a few standard link types (phone, email, SMS, FaceTime, Maps). Apple doesn't support custom link schemes such as shortcuts:// there, so tapping this tag with no app open won't run anything. For true tap-and-go, use Method 1.

Why use it at all? The tag carries its instruction with it. Anyone in your household who has a shortcut with that exact name can scan the same tag and run their own version, and you can always scan the tag to see what it does.

Ideas that work well

  • Bedside: turn on a Sleep Focus, lower the brightness and set tomorrow's alarm.
  • Car mount: get directions home and start a playlist.
  • Desk: turn on a Work Focus and log the start time to a note.
  • Washing machine: start a timer for the cycle length.
  • Front door: run a Home scene if you have HomeKit accessories.

Keep each automation short and predictable. If it does something you'd regret (sending a message, turning off an alarm), choose Run After Confirmation.

Use NFC Toolkit inside your own shortcuts

NFC Toolkit adds actions to the Shortcuts app:

  • Scan NFC Tag opens the app ready to scan. You can also say "Scan a tag with NFC Toolkit" to Siri.
  • Write to NFC Tag opens the app with a website, text, phone number or email address ready to write.
  • Write Wi-Fi to NFC Tag opens the app with a network name and password ready to write.

For example, a shortcut that takes a link from the share sheet and passes it to Write to NFC Tag turns any page into a tag in two taps.

Which tags to use

Any NFC sticker works for Method 1, so cheap NTAG213 stickers are ideal. For Method 2 the link is short, so NTAG213 is plenty. Stick tags somewhere you can reach with the top of your iPhone, and avoid metal surfaces unless you buy on-metal tags.

Troubleshooting

  • The automation asks every time: edit it and choose Run Immediately.
  • Nothing happens: wake the iPhone, close the camera, check Airplane Mode is off, and hold the top edge of the phone to the tag. Check the automation is turned on.
  • No NFC option in Automation: your iPhone model doesn't offer the NFC trigger.
  • Shortcuts opens but shows an error: the name on the tag doesn't match a shortcut on this iPhone. Names are case-sensitive.
